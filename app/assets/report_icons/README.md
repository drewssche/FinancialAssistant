# Report icons

Offline 96×96 transparent masks exported from Lucide 1.17.0 (stroke width 1.7),
the same icons used in the approved report previews. The renderer resizes and
colors these local masks with Pillow; no network, browser, or new runtime
package is required. Unknown categories use `tag`.

Upstream: https://unpkg.com/lucide@1.17.0/dist/umd/lucide.js
